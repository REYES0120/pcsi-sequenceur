# Séquenceur PCSI — étape 5 (saisies)

Étapes 1 à 4 : moteur, données, application. Étape 5 : saisies courtes (chapitre vu, difficulté,
matières prioritaires, rang, DM, DM terminé, annulation d'une saisie), validées par le moteur.

Dans l'application : bouton « Saisies » de l'écran principal.
Chaque saisie enregistrée déclenche un recalcul de la proposition.

Obtenir l'APK : `git add . && git commit -m "etape 5" && git push`, puis onglet « Actions » →
dernier run → artefact `apk-debug`. Si le build est rouge, copie-moi les dernières lignes du log.
